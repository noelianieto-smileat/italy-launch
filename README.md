# Smileat Italy · Paid Media Report

Static site (HTML + CSS) with the first-month Paid Media results for Italy (Meta and Google).

- `index.html` – English version
- `index-es.html` – Spanish version

## Structure

```
index.html
index-es.html
css/styles.css
assets/img/logo-smileat.png
assets/creatividades/   (optimized images and videos)
.nojekyll
```

## Publish with GitHub Pages

1. Upload the folder to a GitHub repository.
2. In **Settings → Pages**, choose branch `main` and folder `/ (root)`.
3. In a few minutes the site will be live at `https://<user>.github.io/<repository>/`.

## Editing data

All figures are written directly in the HTML. The departments in the "Thank you" section are in `#gracias`.
